# Community Code of Conduct

M2RIV is built through precise technical disagreement and respectful collaboration.
Everyone participating in project spaces is expected to make those spaces safe,
welcoming, and useful regardless of background, identity, experience, employer,
or communication style.

## Expected behavior

- Critique ideas, evidence, and code without attacking people.
- State uncertainty and conflicts of interest plainly.
- Give actionable feedback and accept correction without retaliation.
- Respect privacy, embargoed security reports, and confidential model evidence.
- Make room for newcomers and avoid gatekeeping through unexplained jargon.

Harassment, threats, discriminatory language, sexualized attention, doxxing,
deliberate exposure of secrets or private artifacts, and sustained disruption are
not acceptable.

## Enforcement

Report conduct concerns privately to the repository owner through the verified
GitHub profile described in [SECURITY.md](SECURITY.md). Do not post sensitive
details in a public issue. Maintainers will review reports for conflicts of
interest, preserve confidentiality as far as practical, and may issue a warning,
remove content, restrict participation, or permanently ban a participant. A
maintainer named in a report must not decide that report alone.

This code applies in repositories, issue trackers, reviews, discussions, events,
and private communications made in an official project role.
