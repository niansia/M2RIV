# Support

Merriv is pre-alpha infrastructure maintained on a best-effort basis.

- For reproducible bugs, use the bug issue form.
- For Model Change Report compatibility questions, use the compatibility issue form.
- For an independent GPU/corpus reproduction, use the reproduction issue form.
- For a proposed producer, consumer, adapter, metric, or executor, use the plugin
  and integration form.
- For a potential vulnerability, do not open an issue; follow `SECURITY.md` and
  GitHub private vulnerability reporting.

Before opening an issue, search existing issues and include the exact Merriv and
Model Change Report versions, operating system, runtime, non-secret command, exit
code, and the smallest sanitized reproducer. Never upload credentials,
proprietary artifacts, private model outputs, or customer data.

There is no paid support channel, service-level agreement, or private consulting
commitment associated with this repository.
